
# Cloud-Native DevOps Platform

## Overview

A cloud-native application infrastructure project designed to demonstrate
DevOps practices, Infrastructure as Code, containerization,
configuration management, and Kubernetes orchestration.

The project uses a Python REST API application and automates
its deployment and infrastructure management.

## Technologies

- Git
- Python / FastAPI
- Docker / Docker Compose
- Terraform
- AWS-compatible local environment
- Ansible
- Kubernetes
- Jenkins
- Prometheus
- Grafana
- Trivy

## Architecture

The project follows an Infrastructure as Code approach.

Infrastructure provisioning is managed through Terraform,
configuration management through Ansible,
and application deployment through Docker and Kubernetes.

## Project Goals

- Develop and test a Python REST API.
- Containerize the application.
- Provision cloud infrastructure using Terraform.
- Automate server configuration with Ansible.
- Deploy workloads to Kubernetes.
- Implement CI/CD automation.
- Configure monitoring and security scanning.

## Project Status

Currently in development.
